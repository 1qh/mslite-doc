# mslite-doc

Every doc for MuseScoreLite, the owner's lean, offline build of MuseScore, whose code lives in the sibling `mslite` repo.

## Map
- [Patches](adr/patches.md) — what the fork adds to upstream, 1 patch per need.
- [Lean build](adr/lean-build.md) — what the app leaves out, keeps or hides, and why.
- [Release](adr/release.md) — where the app is built, the gates a build passes, and how it is signed and published.
- [Release runbook](runbook/release.md) — the commands for a new upstream release or a patch change.
